Distilled Lithuanian training data, generated by the teacher model
(Qwen/Qwen3-30B-A3B-Instruct-2507-FP8, Apache-2.0) on the first GPU run.

- `synth_sft.qwen3-30b.jsonl.gz`: 9,505 judge-filtered examples across 12 task types
  (context QA, open QA, essays, summaries, grammar, translation, reasoning, ...).

`scripts/gpu_bootstrap.sh` restores it automatically, so later GPU runs skip the
`synth` stage. Note: the judge (the same model) was lenient (mean score 9.96/10), so
some answers still contain small Lithuanian grammar mistakes.
